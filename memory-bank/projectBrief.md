# Help Desk Ticketing System

## Purpose

Deliver a cross-platform help desk solution that lets customers and internal staff log, assign, track, and resolve support tickets with offline capability, push/email notifications, and a secure Express/PostgreSQL backend.

## Target Users

- End customers and employees who need to submit and monitor support tickets on mobile.
- Help desk agents who triage, update, and resolve assigned tickets.
- Admins who oversee workload, manage users/roles, and configure notifications/deployment.


## Project Summary

Multi-platform helpdesk application enabling users to create and track support tickets, agents to manage and resolve tickets, and admins to configure the system. Features AI-powered reply suggestions, configurable workflows for ticket processing, hierarchical category/subcategory organization, and custom dynamic attributes for tickets.



## Goals

- Provide seamless ticket management across web and mobile platforms
- Enable AI-assisted support with automated reply suggestions
- Support configurable workflows for different ticket categories
- Allow custom attributes to extend ticket data dynamically
- Maintain real-time updates and notifications
- Ensure role-based access control and security



## Constraints

- Backend runs on localhost:4000
- Database on PostgreSQL localhost:5434
- Mobile apps built with Expo for iOS and Android
- AI features require OpenAI API key (with fallback)
- Admin features only accessible via web portal



## Stakeholders

- End users (ticket creators)
- Support agents (ticket resolvers)
- System administrators (configuration managers)
- Development team
